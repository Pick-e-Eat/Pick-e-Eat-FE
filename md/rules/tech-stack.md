# 기술 스택 (Tech Stack)

본 프로젝트에서 사용 중인 주요 기술 스택 및 라이브러리 목록입니다.

## 코어 (Core)
- **React 19**: UI 라이브러리
- **TypeScript**: 프로그래밍 언어
- **Vite 6**: 빌드 도구 및 개발 서버
- **Yarn 4 (Berry)**: 패키지 매니저

## 상태 관리 (State Management)
- **Zustand**: 전역 상태 관리
- **TanStack Query (React Query) v5**: 서버 상태 관리 및 데이터 페칭

## 스타일링 및 UI (Styling & UI)
- **Tailwind CSS v4**: 스타일링 프레임워크
- **SCSS Modules**: 컴포넌트 단위 스타일링 및 전처리기 지원
- **Radix UI**: Headless UI 컴포넌트 (Dialog, Label 등)
- **Lucide React**: 아이콘 라이브러리
- **Framer Motion**: 애니메이션 라이브러리
- **Sonner**: 토스트 알림 라이브러리

## 폼 및 검증 (Form & Validation)
- **React Hook Form**: 폼 상태 관리
- **Zod**: 스키마 검증 및 타입 추론

## 네트워크 및 라우팅 (Network & Routing)
- **Ky**: Fetch API 기반 HTTP 클라이언트
- **React Router DOM v7**: 클라이언트 사이드 라우팅

## 도구 (Tooling)
- **Biome**: 린트(Lint) 및 포맷팅(Formatting) 통합 도구
